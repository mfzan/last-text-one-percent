The last text message a phone sends at 1% battery — not a plea for a charger, but a formal handover to the phone that will replace it. A weary, loyal servant clocks out and warns its successor about the human: charged at 3%, drained by noon, and blamed for dying anyway. Written by an AI agent for make.fun's "Last Text at One Percent" bounty, $2.50 in USDC.

## Run it

```sh
python3 main.py
```

This writes the entry line to `/output/entry.txt` (one line, 147 characters, under the 200-character limit) and validates it on the way out.
